### Цель работы

### Содержание работы

- Загрузка справочника сбытовых компаний, поставок электроэнергии и тарифов.
- Аудит качества данных, очистка с журналом изменений и карантином ошибок.
- Создание базы SQLite с ключами и ограничениями.
- Расчёт выручки после усреднения тарифов по каждой поставке.
- Сверка результатов SQL и pandas.
- Рейтинг компаний, ABC/Парето-анализ, сезонность и структура выручки по категориям потребителей.
- Формулирование трёх управленческих рекомендаций.
